# Personal Expense Tracker (CSE103)

এটি একটি C ল্যাঙ্গুয়েজে তৈরি কনসোল অ্যাপ্লিকেশন, যা দৈনন্দিন খরচের হিসাব রাখতে সাহায্য করে। এই প্রজেক্টটি East West University-এর CSE103 (Structured Programming) কোর্সের অংশ হিসেবে তৈরি করা হয়েছে।

## Features
- **Add Expense:** নতুন খরচের হিসাব যোগ করা।
- **Display All:** সব খরচের তালিকা টেবিল আকারে দেখা।
- **Search by Category:** নির্দিষ্ট ক্যাটাগরি অনুযায়ী খরচ খোঁজা।
- **Update Expense:** ভুল এন্ট্রি সংশোধন করা।
- **Show Total:** মোট খরচের পরিমাণ দেখা।
- **Persistent Storage:** `expenses.txt` ফাইলে ডেটা সেভ থাকে, তাই প্রোগ্রাম বন্ধ করলেও ডাটা হারায় না।

## How to Run
1. নিশ্চিত করুন আপনার কম্পিউটারে GCC কম্পাইলার আছে।
2. কোডটি কম্পাইল করুন: `gcc expense_tracker.c -o expense_tracker`
3. প্রোগ্রামটি চালান: `./expense_tracker`
